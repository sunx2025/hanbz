# basic-vowels
## 基础元音
ㅏ ㅓ ㅗ ㅜ ㅡ ㅣ及无声初声ㅇ

### title.overview
#### 韩语文字
一个韩语文字通常由初声（辅音）、中声（元音）和可选的收音（终声）组成。  

ㄱ（初声）+ ㅏ（中声）→ 가（文字）
ㄱ（初声）+ ㅏ（中声）+ ㄴ（收音）→ 간（文字）

#### 基础元音

| hangul | note | sound |
| ------ | ---- | ----- |
| ㅏ      | a    |       |
| ㅓ      | eo   |       |
| ㅗ      | o    |       |
| ㅜ      | u    |       |
| ㅡ      | eu   |       |
| ㅣ      | i    |       |

#### 无声初声
当 ㅇ 位于文字开头时，不发音。

| hangul | note    | sound |
| ------ | ------- | :---: |
| ㅇ      | 作初声时不发音 |   -   |

#### 基础音节
“ㅇ”与元音组合，形成文字。 由于“ㅇ”不发音，这些文字的发音与单个元音相同。

| hangul | note | sound |
| ------ | :--: | :---: |
| 아      |  a   |       |
| 어      |  eo  |       |
| 오      |  o   |       |
| 우      |  u   |       |
| 으      |  eu  |       |
| 이      |  i   |       |
