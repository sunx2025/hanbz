# basic-vowels
## Basic Vowels
ㅏ ㅓ ㅗ ㅜ ㅡ ㅣ and silence initial ㅇ

### title.overview
#### Hangul Syllables
A Korean syllable usually consists of an initial consonant, a vowel, and an optional final consonant.  

ㄱ (initial) + ㅏ (vowel) → 가 (syllable)  
ㄱ (initial) + ㅏ (vowel) + ㄴ (final) → 간 (syllable)

#### Basic Vowels
| hangul | note | sound |
| ------ | ---- | ----- |
| ㅏ      | a    |       |
| ㅓ      | eo   |       |
| ㅗ      | o    |       |
| ㅜ      | u    |       |
| ㅡ      | eu   |       |
| ㅣ      | i    |       |

#### Silent Initial
When “ㅇ” appears at the beginning of a syllable, it is silent.

| hangul | note                 | sound |
| ------ | -------------------- | :---: |
| ㅇ      | Silent as an initial |   -   |

#### Basic Syllables
When “ㅇ” combines with a vowel, it forms a syllable. Because “ㅇ” is silent, the syllable sounds the same as the vowel.

| hangul | note | sound |
| ------ | :--: | :---: |
| 아      |  a   |       |
| 어      |  eo  |       |
| 오      |  o   |       |
| 우      |  u   |       |
| 으      |  eu  |       |
| 이      |  i   |       |

# y-vowels
## Y Series Vowels ㅑ ㅕ ㅛ ㅠ
Learn the Y series vowels and combine them with ㅇ ㄱ ㄴ

### title.overview
#### Y Series Vowels
In this vowel family, an extra short stroke adds a brief y sound at the beginning. The original direction of the vowel stays the same.

| hangul | note | sound |
| ------ | ---- | :---: |
| ㅑ      | ㅏ a → ㅑ ya |       |
| ㅕ      | ㅓ eo → ㅕ yeo |       |
| ㅛ      | ㅗ o → ㅛ yo |       |
| ㅠ      | ㅜ u → ㅠ yu |       |

#### Combined with Silent Initial ㅇ
ㅇ is silent at the beginning of a syllable. ㅑ ㅕ sit to its right, while ㅛ ㅠ sit below it.

| hangul | note | sound |
| ------ | ---- | :---: |
| 야      | 아 a → 야 ya |       |
| 여      | 어 eo → 여 yeo |       |
| 요      | 오 o → 요 yo |       |
| 유      | 우 u → 유 yu |       |

#### Combined with ㄱ ㄴ
Keep the consonant and replace the basic vowel with its Y counterpart.

| hangul | note | sound |
| ------ | ---- | :---: |
| 갸      | gya |       |
| 겨      | gyeo |       |
| 교      | gyo |       |
| 규      | gyu |       |
| 냐      | nya |       |
| 녀      | nyeo |       |
| 뇨      | nyo |       |
| 뉴      | nyu |       |
