# basic-vowels
## Basic Vowels
ㅏ ㅓ ㅗ ㅜ ㅡ ㅣ and silence initial ㅇ

### title.overview
#### Hangul Syllables
A Korean syllable usually consists of an initial consonant, a vowel, and an optional final consonant.  

ㄱ (initial) + ㅏ (vowel) → 가 (syllable)  
ㄱ (initial) + ㅏ (vowel) + ㄴ (final) → 간 (syllable)

#### Basic Vowels
| hangul | note | sound |
| ------ | ---- | ----- |
| ㅏ      | a    |       |
| ㅓ      | eo   |       |
| ㅗ      | o    |       |
| ㅜ      | u    |       |
| ㅡ      | eu   |       |
| ㅣ      | i    |       |

#### Silent Initial
When “ㅇ” appears at the beginning of a syllable, it is silent.

| hangul | note                 | sound |
| ------ | -------------------- | :---: |
| ㅇ      | Silent as an initial |   -   |

#### Basic Syllables
When “ㅇ” combines with a vowel, it forms a syllable. Because “ㅇ” is silent, the syllable sounds the same as the vowel.

| hangul | note | sound |
| ------ | :--: | :---: |
| 아      |  a   |       |
| 어      |  eo  |       |
| 오      |  o   |       |
| 우      |  u   |       |
| 으      |  eu  |       |
| 이      |  i   |       |
